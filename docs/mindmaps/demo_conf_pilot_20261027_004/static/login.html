Eerste eigenaar inrichten

Alleen vóór de eerste inrichting. Lees de eenmalige activeringscode in je eigen Server4-terminal: cat ~/.local/state/server4-mobile-demo/owner-activation. De code blijft lokaal en wordt na gebruik verwijderd. Kies zelf een wachtwoord; deel het niet in chat.

Toegang uitsluitend via de bestaande private tunnel. Werkelijke HTTPS-/telefoonacceptatie en productieafspraken blijven afzonderlijk nodig.
